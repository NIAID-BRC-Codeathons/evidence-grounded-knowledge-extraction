Extraction curator

Runs the extraction pipeline over RAGStack and Argo. The API key stays on this server; this page never calls RAGStack directly. For a dedicated row-by-row spot-check view, use the spot-check page with a file drawn by sample.py.

Start here

  1. A single extraction reads a handful of papers about one gene and pulls out claims, each one tied to the exact sentence in the paper that backs it up.
  2. Queueing a batch runs that same extraction for several genes, one after another, so you can leave it working instead of clicking Run each time.
  3. The prompt panel lets you edit the instructions sent to the model and rerun the same papers, so you can see how a wording change affects the results.
  4. The jobs list shows every run you have started, with live progress, and lets you open any of them to see its rows or stop it early.
